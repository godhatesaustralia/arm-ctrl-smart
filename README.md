## IED F2026 - SMART
# Arm controller for Arduino

### NOTE
This project is configured for Windows VSCode. You *must* have:
- a C++ compiler (one would hope)
- the C++ extension for VSCode installed and enabled
- the Arduino extension for VSCode installed and enabled
- the Arduino IDE installed in its **default location**
- the following Arduino libraries in the **default directory** for such:
  - BasicLinearAlgebra
  - Geometry
  - Kinematics
  
  These can be easily installed using the aforementioned Arduino IDE.
